# Lessons for KOML

Synthetic evidence validates exact arithmetic, deterministic qualification and rejection rules. It does not validate the assumption that eligible records become buyers, or that Henry will use this tool daily. The build separates those unresolved questions from local correctness.

The domain lesson is that a stated need, contact, recorded consent and budget are distinct facts. Missing one must produce an explicit reason, not an invented score. Filtering dossiers also requires recomputing the displayed totals and provenance so every number reconciles with the displayed records.

Operating rule: plant independently computed labels before building the report, then mutate one input and require its output to change. Keep commercial verdicts pending until real-use evidence exists.
